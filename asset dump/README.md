# Pixel Platformer Underground Cave and Crystal Tileset (16x16)
209 sprites by reodesuxz.
- 5 terrain sets: Cave Stone, Crystal Cavern, Lava Rock, Ice Cave, Mine Dirt. Each: 3x3 auto-tile set, fill variant, single block, 3-tile one-way platform
- Liquids: lava, acid, water (2-frame animated surfaces + fill); 4 background tiles
- Crystals and ores (16), cave decor (26), hazards (14), props (28), gadgets, moving platforms, collectibles (12), enemies (10)
Files: PNG/native + PNG/x4 (nearest), tileset.png + tileset.tsx (Tiled), spritesheet.png + spritesheet.json, sample_level.png, animations/ (sheets + GIFs)
Unity/Godot/GameMaker: Filter Mode = Point / Nearest, Compression = None, pixels-per-unit 16.
